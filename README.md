# いろスケッチ
https://nagaokayama.github.io/color-ribbon-sketch/
依存ライブラリとビルド処理を使わない、ブラウザ向けのお絵かきアプリです。`dist/index.html` を開くと起動します。

キャンバスの画像サイズは1024×1024ピクセルです。初期表示は縦横とも画面内に収まる倍率に合わせます。描画ツールの下の＋／−で表示倍率を変更でき、拡大後は縦横のスクロールで移動します。「画面に合わせる」でキャンバス全体を表示します。白背景の上に透明な描画レイヤーを1枚固定し、レイヤー操作は設けていません。表示倍率を変えても画像サイズとペンのピクセルサイズ、PNG出力は変わりません。

ペンと消しゴムは丸型、硬い輪郭です。ペンの不透明度は0〜100%で調整できます（初期値100%）。1ストローク内の重なりでは不透明度を加算せず、別ストロークを重ねると合成します。消しゴムは不透明度100%のままです。ペンと消しゴムのサイズは、それぞれ別のスライダーで1〜100ピクセルに変更できます。筆圧は使いません。Undo/Redoは最大10ストロークに対応し、取り消した後に描くとRedo履歴を破棄します。入力が中断されたストロークは破棄します。

各色セットは5色固定です。左端を影（S）、中央をベース（B）、右端をハイライト（H）とし、中間の2色はそれぞれの中間色です。調整前のベース色はHSVとカラーピッカーで編集します。5色は、この色とセットごとのRamp設定から生成します。

Shadow HueとLight HueはBからの色相差で、±30度の範囲で調整します。Shadow DepthはBの明度から黒へ、HighlightはBの明度から100へ近づける割合で、0〜100%に設定できます。計算結果の明度は100を上限にします。影の彩度はBに対する変化率を−30〜+30%で表示し、倍率は70〜130%です。ハイライトの彩度はHSVのSを0〜100%で直接指定します。中間色の彩度はBとハイライトの平均です。JSONはバージョン2で保存し、バージョン1のハイライト彩度倍率は読み込み時に絶対値へ変換します（整数に丸めます）。影の暗さはスライダーの左端で黒、右端でBと同じ明度になります。JSON内のshadowDepthは従来どおり暗くする割合を保存します。制限を超える設定を含む既存JSONはロード時にエラーとし、現在のセットを保持します。中間色はBから各端点への変化量を半分にします。Bは影・ハイライトの調整では変化しません。生成式は参照項目に基づく独自実装です。

「影・ハイライトの変更を全セットに適用」をオンにすると、その後に動かした調整項目を現在の全セットで同じ値にします。チェックしただけでは色を変更しません。ベース色と操作していない項目は各セットの値を保持します。チェック状態はJSONには保存しません。

スポイトは描画色だけを取得し、色セットを書き換えません。色の変更は既存の線には適用しません。

PNGには白背景を合成します。ファイル名は保存操作時の端末の日時とランダムな英語の動物名を使い、`YYYYMMDD-HHmm-animal.png`（例：`20261020-0935-otter.png`）にします。描画内容の永続保存は行いません。色セットは「セットを保存」でJSONファイルに保存し、「セットをロード」で復元できます。全セットの順序・ベース色・影とハイライトの調整設定を保存します。ロードは現在の全セットを置き換え、最初のセットのベース色を選択します。描画内容とUndo/Redo履歴は変更しません。不正なファイルを読み込んだ場合は現在のセットを保持します。自動保存は行いません。

`dist/app.js` は描画・履歴・色セット、`dist/style.css` は画面配置、`dist/index.html` は画面構造を担当します。

## 検証

`node --check dist/app.js` で構文を確認できます。ブラウザでは、描画・消去・10回の取り消しとやり直し・スポイト・色調整・PNGの1024×1024出力を確認します。
