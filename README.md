# いろスケッチ

依存ライブラリとビルド処理を使わない、ブラウザ向けのお絵かきアプリです。`dist/index.html` を開くと起動します。

キャンバスの画像サイズは1024×1024ピクセルです。表示幅が収まらない場合は縦横比を維持して縮小し、縦方向はスクロールして表示します。白背景の上に透明な描画レイヤーを1枚固定し、レイヤー操作とズームは設けていません。

ペンと消しゴムは丸型、硬い輪郭、不透明度100%です。ペンと消しゴムのサイズは、それぞれ別のスライダーで1〜100ピクセルに変更できます。筆圧は使いません。Undo/Redoは最大10ストロークに対応し、取り消した後に描くとRedo履歴を破棄します。入力が中断されたストロークは破棄します。

各色セットは5色固定です。左端を影（S）、中央をベース（B）、右端をハイライト（H）とし、中間の2色はそれぞれの中間色です。BはHSVとカラーピッカーで編集します。残り4色はセットごとのRamp設定から生成します。

Shadow HueとLight HueはBからの色相差（度）です。Shadow DepthはBの明度から黒へ、HighlightはBの明度から白へ近づける割合です。Saturationは派生色の彩度倍率で、Shadow SatとHighlight Satは端点での追加倍率です。中間色はBから各端点への変化量を半分にします。BはRamp設定で変化しません。生成式は参照項目に基づく独自実装です。

スポイトは描画色だけを取得し、色セットを書き換えません。色の変更は既存の線には適用しません。

PNGには白背景を合成します。描画内容と色セットの永続保存は行いません。

`dist/app.js` は描画・履歴・色セット、`dist/style.css` は画面配置、`dist/index.html` は画面構造を担当します。

## 検証

`node --check dist/app.js` で構文を確認できます。ブラウザでは、描画・消去・10回の取り消しとやり直し・スポイト・色調整・PNGの1024×1024出力を確認します。
